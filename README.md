# Assessment Calculator

Консольные скрипты для браузера для парсинга страниц оценки Alfa People и расчёта грейдов на основе коэффициентов навыков.

## Обзор

Проект содержит JavaScript-утилиты, которые запускаются в консоли браузера и позволяют:
- Парсить чекбоксы оценки на всех вкладках
- Рассчитывать коэффициенты по уровням (Intern → Junior → Middle → Senior)
- Определять итоговый грейд на основе суммы коэффициентов

## Таблица грейдов

| Диапазон коэффициента | Грейд |
|-----------------------|-------|
| 0.0 – 0.9 | Не определен |
| 0.9 – 1.8 | Intern |
| 1.8 – 2.25 | Junior |
| 2.25 – 2.7 | Junior+ |
| 2.7 – 3.15 | Middle |
| 3.15 – 3.6 | Middle+ |
| 3.6 – 3.8 | Senior |
| 3.8 – 4.0 | Senior+ |

## Использование

1. Откройте страницу оценки в браузере
2. Откройте DevTools (F12) → Консоль
3. Скопируйте и вставьте содержимое файла `parse_assessment.js`
4. Нажмите Enter

Скрипт автоматически:
- Раскроет все свёрнутые секции
- Пройдёт по всем вкладкам
- Рассчитает промежуточные и итоговые грейды
- Выведет результаты в консоль

## Файлы

| Файл | Описание |
|------|----------|
| `parse_assessment.js` | Основной скрипт с разбивкой по категориям |
| `assessment-calculator.md` | Подробная документация |
| `example/*.html` | Референсные HTML-файлы для тестирования |

## Алгоритм

1. **Промежуточный расчёт**: Для каждой вкладки (Базовые, Технические, Продуктовые) рассчитывается коэффициент по уровням
2. **Коэффициент уровня**: `отмечено / всего` (округление до 3 знаков)
3. **Сумма категории**: Сумма коэффициентов уровней внутри категории
4. **Итоговый грейд**: На основе общего коэффициента по всем категориям

Исключённые вкладки: **Дополнительная активность**
